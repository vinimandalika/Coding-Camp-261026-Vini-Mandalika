## 🌸 About

**Pinky Budget ♡** is a mobile-friendly expense tracker and budget visualizer built as part of the RevoU Software Engineering Fundamentals Mini Project. It combines elegant design with practical functionality to help you track your spending in style.

## ✨ Features

### Core Features (MVP)
- ✅ **Expense Input Form** — Add transactions with name, amount, and category
- ✅ **Transaction List** — View and delete individual expenses
- ✅ **Total Expenses** — Automatic calculation with Rupiah formatting
- ✅ **Spending Distribution Chart** — Interactive pie chart visualization

### Optional Features
- 📊 **Monthly Summary** — View current month spending by category
- 🔄 **Transaction Sorting** — Sort by newest, oldest, highest, or lowest
- 🌙 **Dark/Light Mode** — Toggle between themes with localStorage persistence

## 🎨 Design

The interface features:
- Soft pastel pink color palette

## 🚀 Getting Started

1. **Clone or download** this repository
2. **Open** `index.html` in a modern web browser
3. **Start tracking** your expenses!

No installation or build process required. Everything runs client-side in your browser.

## 💡 How to Use

### Adding Expenses
1. Navigate to the **Dashboard**
2. Fill in the "Add New Expense" form:
   - Item Name (e.g., "Coffee")
   - Amount in Rupiah
   - Category (Food, Transport, or Fun)
3. Click "Add Expense ♡"

### Viewing Transactions
- **Dashboard** shows recent 5 transactions
- **Transactions** page shows all with sorting options
- Click "Delete" to remove any transaction

### Monthly Summary
- View current month's total spending
- See breakdown by category (Food, Transport, Fun)
- Updates automatically as you add/delete transactions

### Theme Toggle
- Go to **Settings**
- Toggle between Light Mode 🌸 and Dark Mode 🌙
- Your preference is saved automatically

## 📊 Data Storage

All data is stored locally in your browser using localStorage:
- **Transactions** — All expense records
- **Theme Preference** — Light or dark mode selection

Your data persists even after closing the browser, but remains private to your device.
